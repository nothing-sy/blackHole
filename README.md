# DesktopBlackHole

桌面浮动黑洞：靠近区域会扭曲真实桌面画面；把文件拖进去即送入回收站。回收站越大黑洞越大，双击清空回收站并恢复初始大小。

## 运行

```bash
npm install
npm start
```

## 用法

- 拖动中心区域移动窗口
- 靠近黑洞的桌面内容会被吸入扭曲（屏幕采集 + WebGL）
- 拖入文件/文件夹 → 回收站
- 双击中心：清空回收站，黑洞回到最小
- 右键：置顶 / 清空 / 隐藏 / 退出

## 打包

```bash
npm run dist
```

## 说明

扭曲层是置顶透明窗对屏幕采集的实时变形，并非改写其他进程像素。采集失败时会降级为仅显示黑洞本体。
